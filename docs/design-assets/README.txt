MEALS WITH HONOR — OPTION A DESIGN ASSETS
For WordPress development. Client-approved design: "Option A — Patriotic"
(navy / red / white, Oswald + Source Sans 3).

CONTENTS
--------
Meals-with-Honor-OptionA-Style-Guide.pdf
    Full spec reference: colors, typography, buttons, cards, spacing,
    breakpoints, icon list, image asset manifest, and WordPress build notes.
    Start here.

design-tokens.css
    CSS custom properties (colors, fonts, radii, spacing) plus base
    component styles (buttons, cards, headings). Drop into your theme's
    stylesheet as a starting point.

/icons
    7 SVG icons used across the page, 24x24 viewBox, currentColor
    fill/stroke so they can be recolored via CSS.

/images
    Photography from the approved mockup (hero, Who We Serve, gallery,
    news). IMPORTANT: these are the CC-licensed stock photos used to
    build the mockup, sized only for on-screen preview. Replace with the
    organization's own photography (or verify/renew licensing and source
    higher-resolution versions) before launch — see the manifest in the
    style guide for recommended minimum widths per image.

/logo
    logo.png (original, 304x338, opaque white background) plus generated
    favicon sizes: 16, 32, 180 (Apple touch), and 512px.

NOT INCLUDED
------------
The full-page mockup HTML/canvas (desktop + mobile) was delivered
separately as the approved Claude Design artifact and PDF — this package
is the build-ready asset set extracted from that approved design.
